# Random Quote Generator

This project is a simple random quote generator that displays a random quote from a predefined list of quotes.

## Files

- `index.html`: The main HTML file that contains the structure of the page.
- `style.css`: The CSS file that contains the styles for the page.
- `script.js`: The JavaScript file that contains the logic for generating random quotes.

## Usage

1. Open the `index.html` file in your browser.
2. Click the "New Quote" button to display a new random quote.
